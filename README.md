# Esquisita como eu - Landing page acessível

Landing page da obra *Esquisita como eu*, de Laura Castilhos, desenvolvida com foco em acessibilidade para o público infantil.

🔗 [Acesse a página](https://acervo-acessivel.github.io/esquisita-como-eu/)

## Contexto acadêmico
Projeto desenvolvido na disciplina **Práticas e Projetos Inclusivos**, do Programa de Pós-Graduação em Design (PGDesign) da UFRGS, semestre 2026/2.  

Professor: Eduardo Cardoso  
Discentes: Inessa Luerce, Thainá Santos

## Entregas
- Audiodescrição da obra
- Audiodescrição da biografia da artista
- Adaptação da biografia da artista para linguagem simples
- Card impresso para distribuição em museu
- Placa tátil produzida por impressão 3D

## Acessibilidade do site
- Conformidade com WCAG 2.1 AA
- Navegação completa por teclado
- Compatível com leitores de tela
- Contraste verificado, textos em linguagem simples
- Respeita `prefers-reduced-motion`

## Tecnologias
HTML, CSS e JavaScript puro, sem frameworks. Layout responsivo em três breakpoints (375, 800 e 1440px), design no Figma.
